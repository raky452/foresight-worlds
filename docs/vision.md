# Vision

AI agents are moving from answering questions to taking actions. Before an agent is trusted with a real inbox, a real customer record or a real payment, its builders need to know how it behaves: what it does when an instruction is ambiguous, when a tool fails halfway, when data is missing, or when someone tries to trick it.

Foresight Worlds aims to make that testing routine:

1. **Digital worlds** that reproduce the systems agents work in, with realistic state and rules.
2. **Scenarios** that can be replayed exactly, including injected failures and adversarial inputs.
3. **Behaviour traces** that record every observation, decision and change an agent makes.
4. **Converters** that export traces and world state into formats humans and other systems already use, so results can be analysed, reviewed and shared.
5. **Standard connections** (such as MCP) so any agent, from any vendor, can enter a world without custom integration.

The converters come first because they are useful on their own today, and because every simulation ends by exporting something.
